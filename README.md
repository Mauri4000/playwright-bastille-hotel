# playwright-bastille-hotel

Professional BDD/Cucumber E2E automation framework for Bastille Hotel.

## Stack

- **[Playwright](https://playwright.dev/)** — browser automation
- **[@cucumber/cucumber](https://cucumber.io/)** — BDD with Gherkin feature files
- **[Allure](https://docs.qameta.io/allure/)** — beautiful HTML test reports
- **TypeScript** — strict typing throughout
- **GitHub Actions** — CI/CD: smoke → e2e pipeline on `develop` branch

## Design patterns

| Pattern     | Where used |
|-------------|------------|
| Page Object Model | `src/pages/` — one class per page |
| Inheritance | All pages extend `BasePage` |
| Interfaces  | `IPage`, `IFactory`, `IBuilder` in `src/core/interfaces/` |
| Singleton   | `BrowserManager` — one browser for the whole run |
| Builder     | `ReservationBuilder`, `TransactionBuilder` |
| Factory     | `ReservationFactory`, `TransactionFactory` — named presets |

## Folder structure

```
playwright-bastille-hotel/
├── src/
│   ├── core/
│   │   ├── interfaces/     # IPage, IFactory, IBuilder
│   │   ├── BasePage.ts     # Abstract base — all pages inherit this
│   │   ├── BrowserManager.ts  # Singleton
│   │   └── WorldContext.ts    # Cucumber World
│   ├── pages/              # LoginPage, CalendarPage, DashboardPage, PublicRoomsPage
│   ├── builders/           # ReservationBuilder, TransactionBuilder
│   ├── factories/          # ReservationFactory, TransactionFactory
│   └── utils/              # Config, Logger, DateUtils
├── tests/
│   ├── features/           # *.feature (Gherkin + @smoke/@e2e tags)
│   └── steps/              # Step definitions (TypeScript)
├── hooks/
│   └── hooks.ts            # Before/After + cleanup
├── reports/
│   └── allure-results/     # Generated by Allure
├── .github/
│   └── workflows/
│       └── e2e.yml         # CI/CD pipeline
├── cucumber.json           # Profiles: default, smoke, e2e, regression
├── tsconfig.json
└── package.json
```

## Setup

```bash
cp .env.example .env
# Fill in BASE_URL, ADMIN_URL, TEST_EMAIL, TEST_PASSWORD

npm install
npx playwright install chromium
```

## Running tests

```bash
# All tests
npm test

# Smoke only (@smoke)
npm run test:smoke

# E2E only (@e2e)
npm run test:e2e

# All regression (@smoke or @e2e)
npm run test:regression
```

## Viewing the Allure report

```bash
npm run report
```

## CI/CD (GitHub Actions)

Push to `develop` → smoke tests run first → e2e tests run only if smoke passes.

### Required GitHub Secrets

| Secret | Value |
|--------|-------|
| `TEST_BASE_URL` | Public site URL |
| `TEST_ADMIN_URL` | Admin panel URL |
| `TEST_EMAIL` | Test user email (created in Supabase) |
| `TEST_PASSWORD` | Test user password |

## Before first run (manual steps)

1. Create a `develop` branch:
   ```bash
   git checkout -b develop
   git push -u origin develop
   ```
2. Create a test user in Supabase Auth with email/password matching your `.env`.
3. Add the four GitHub Secrets above in **Settings → Secrets → Actions**.
